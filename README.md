<h1 align="center">Stilbe</h1>

<p align="center">A browser for macOS with an agent that works alongside you.</p>

This repository holds Stilbe's downloads and the files the app checks for updates. There's no source code here.

- **To download Stilbe**, use the link you were given, or go to [stilbe.app](https://stilbe.app).
- **Already have it?** Stilbe updates itself from the [releases](https://github.com/stilbe-app/browser-releases/releases) here, so there's nothing to do.

Questions or problems: [support@stilbe.app](mailto:support@stilbe.app).
